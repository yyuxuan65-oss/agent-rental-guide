# 你的 AI 实习生 · 使用指南

面向小白租户的单页使用说明，把「Agent = 实习生」的心智植入客户：**需要养、教、培养，越用越懂你**。

## 本地预览

双击 `index.html`，用浏览器直接打开即可。

## 部署到 GitHub Pages（三步）

1. 把整个目录推到一个 GitHub 仓库
2. 仓库 **Settings → Pages → Source** 选 `main` 分支、根目录 `/`
3. 保存后约 1 分钟生效，访问 `https://<用户名>.github.io/<仓库名>/`

## 改内容

所有文案都在 `index.html` 里，改文字、换颜色直接编辑保存，刷新即见。
